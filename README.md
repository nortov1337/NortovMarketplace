# Nortov Marketplace

Витрина на Next.js с поиском, фильтрами, избранным и корзиной. Данные товаров демонстрационные, корзина хранится в браузере.

## Запуск

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. Для производственной сборки используйте `npm run build` и `npm start`.

Проект не принимает реальные заказы и платежи. Для коммерческого запуска потребуются серверные учетные записи, база данных, управление продавцами и остатками, интеграции оплаты и доставки, защита и эксплуатационная инфраструктура.
