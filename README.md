# Nortov Marketplace

Маркетплейс на Next.js с каталогом и заказами без встроенной онлайн-оплаты.

## Возможности

- Регистрация и вход по электронной почте и паролю; пароль хранится в виде хеша scrypt, сессия — в HttpOnly cookie.
- Каталог, поиск, категории, сортировка, избранное и корзина.
- Кабинет продавца: добавление и изменение товаров, управление остатками и доступностью.
- Оформление заказа с адресом и телефоном, просмотр заказов покупателем и обработка продавцом. Остатки проверяются и списываются в транзакции, при отмене продавцом возвращаются.
- Оплата и способ доставки согласуются между покупателем и продавцом вне сервиса.

## Запуск

Требуется Node.js 24 и npm.

```sh
npm install
npm run dev
```

Откройте http://localhost:3000, зарегистрируйтесь и добавьте товар в кабинете продавца. Для проверки покупки используйте второй аккаунт: продавец не может заказать собственный товар.

Для сборки используйте `npm run build`, затем `npm start`. При локальной проверке production-сборки по HTTP задайте `COOKIE_SECURE=false`; на публичном сервере используйте HTTPS и не отключайте защиту cookie.

SQLite хранится в `data/marketplace.sqlite`; каталог можно изменить переменной `DATA_DIR`. Не размещайте базу в публичном каталоге и настройте её резервное копирование. Встроенный `node:sqlite` в Node.js помечен экспериментальным.

## Перед публичным запуском

Текущая версия подходит для разработки и проверки сценариев. Для эксплуатации с реальными пользователями ещё нужны подтверждение почты и восстановление пароля, защита от перебора и спама, модерация, политика конфиденциальности и обработка персональных данных, мониторинг и резервное копирование, аудит безопасности, а также согласованная схема доставки и разрешения споров. SQLite на локальном диске требует постоянного хранилища и не подходит для нескольких независимых экземпляров приложения без изменения архитектуры. Не используйте временную файловую систему или статический хостинг для базы.
